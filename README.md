# Quotiq

A creative space to share quotes, express yourself through drawings, and turn your words into designed cards.

## Features
- Search quotes and browse automatically assigned categories
- Publish text, drawings, or both
- Design quote cards and download posts as PNG images
- Save favorites, repost quotes, and create personal collections
- Publish a Golden Daily Quote that expires after 24 hours

## Built With
PHP · JavaScript · HTML · CSS · Laravel · Blade · Vite · SQLite · PostgreSQL · Docker · Render · Neon
